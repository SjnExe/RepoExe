# RepoExe

A robust, multi-format package repository built for Termux, Alpine, Arch, NPM, and PIP environments.

## Quick Start

To bootstrap the RepoExe CLI and enable the main repository components, simply run:

```bash
curl -sL https://sjnexe.github.io/RepoExe/install | sh -s -- --bootstrap
repoexe enable all
```

For GUI/X11 applications, run:
```bash
repoexe enable x11
```

Check out `repoexe help` for more information on available commands.
